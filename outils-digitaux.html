❓ Questions fréquentes

Tout ce que vous
devez savoir

Est-ce que l'outil sera intégré à mon site existant ? +

Oui — nous intégrons l'outil directement sur votre site web existant, sur une nouvelle page dédiée. Aucune action technique de votre part n'est nécessaire.

Je n'ai pas de site web — est-ce possible quand même ? +

Absolument. Nous pouvons créer une page autonome hébergée chez nous (ex: votreoutil.proxybotpro.fr) ou vous proposer également la création de votre site web complet.

Combien de temps pour recevoir mon outil ? +

Entre 3 et 7 jours ouvrés selon la complexité. Nous commençons toujours par une maquette validée avec vous avant de développer.

Puis-je modifier l'outil après livraison ? +

Oui — chaque formule inclut des modifications gratuites (1 pour Avancé, 3 pour Sur Mesure). Au-delà, les modifications sont facturées selon leur complexité.

Les notifications email sont-elles vraiment automatiques ? +

Oui — dès qu'un utilisateur utilise votre outil, vous recevez un email récapitulatif avec ses informations et résultats. Votre client reçoit également une confirmation automatique.
